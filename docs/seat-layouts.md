# 三种影厅座位布局（2026-11-17）

当前演示布局改为按影厅类型生成，不再统一使用 12 排 × 6 座：

- STANDARD：10 排、168 座；前排 14 座，逐渐扩展至 18 座；三个座区、两条纵向过道，第 4 排后设横向通道。
- IMAX：12 排、300 座；前排 22 座，逐渐扩展至 26 座；14 座的宽中央区、两侧座区和纵向过道，第 4 排后设横向通道。
- DOLBY_CINEMA：8 排、92 座；前两排每排 10 座，其余每排 12 座；两大座区、中间宽过道；界面采用更宽的躺椅轮廓和更大排距。

这些排数、座数是本项目选定的代表性方案，不是品牌统一标准，也不是项目中九家实体影院的实测座位图。座椅和排距的显示比例不表示施工尺寸。

## 现实参考

资料核对日期：2026-11-17。

- [ICA 影院参观指南](https://www.ica.art/visual-story-guide)：提供普通影院座位图、入口位置，以及固定靠背、非躺椅的座椅说明；参考其实体厅分区和通道设计思路。
- [HOYTS 的 IMAX 说明](https://support.hoyts.com.au/hc/en-us/articles/50667258089875-IMAX)：定制厅体几何、阶梯座席和大银幕；参考其强调视线与大空间的布局特点。
- [IMAX Victoria 的座位图](https://imaxvictoria.com/wp-content/uploads/2016/11/IMAX-Theatre-Seat-Map.pdf)：公开座位图列出每排数十个座位，说明宽幅、多列布局与原来的六列长条演示差别很大。
- [Pathé 的 Dolby Cinema 介绍](https://www.pathe.com/en/cinemas/dolby-cinema-the-exceptional-experience/)：其影院使用更宽的可调躺椅，并描述两米排距；本项目参考舒适座椅和较疏排布，不将该尺寸视为所有杜比厅的强制标准。

## 运行与数据库更新

新数据库的种子数据、新增影院、扩展片单创建的影厅，均使用 `cinema/seating.py` 的同一套生成规则。店长创建布局时，默认提供当前影厅类型的推荐方案，也保留手动设置排数、分段和银幕方向。

已有数据库先预览，再应用：

```sh
.venv/bin/python scripts/upgrade_seat_layouts.py
.venv/bin/python scripts/upgrade_seat_layouts.py --apply
```

命令行只允许连接 `.env` 中的 `cinema_demo`。脚本只自动升级原始的 12 × 6 演示布局；自定义布局保持不变。每个影厅新增不可变的布局版本，所有旧布局、座位 ID 均保留。

只调整未来、仍在售、且没有任何订单、占座历史或座位占用的场次，并增加场次版本号。过去场次和有历史记录的场次继续使用原布局。前端若还缓存旧座位 ID，提交时会被后端拒绝，应刷新座位图后重选。

脚本与订票、排片操作共用物理影厅锁的顺序，整个更新在事务内完成；重复执行不会重复建布局或改场次。应用前将布局、座位和场次快照保存到 `instance/seat-layouts/`（权限 0600，受 Git 忽略）；该快照不是整个数据库备份。

组员拉取代码后，在自己的本地库执行上述升级命令；数据库内容不会随 Git 推送自动更新。已有日期的片单导入允许保留旧布局版本的场次，新场次采用影厅最新布局。

## 选座逻辑

`map_x/map_y` 描述平面位置，空列为纵向过道、空行为横向通道。界面明确设置空行高度，避免 CSS Grid 把通道压没。座位号在同排连续，跨过道时 `aisle_segment` 改变，连座推荐不能跨过道拼接。逻辑排号仍用于前／中／后区偏好；售出、占座、签名报价、支付和改签继续按真实座位 ID 工作。

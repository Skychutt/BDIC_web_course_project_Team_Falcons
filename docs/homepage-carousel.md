## 前端行为

使用 Flask 提供的原生 JavaScript ES 模块和 CSS，无需增加框架或构建步骤。

- `catalogue.js` 从数据库片单渲染所有非归档影片；图片、简介、评分和两条入口随对应影片一起切换。
- `featured-carousel.js` 每 6 秒切换下一部，最后一部循环回第一部。片数来自实际目录，后续新增影片会自动纳入。
- 仅保留上一部、下一部两个箭头；按用户后续要求移除底部切换点、计数和暂停／播放按钮。
- 鼠标悬停、键盘进入轮播或页面隐藏时暂停；系统设置“减少动态效果”时默认暂停并移除过渡动画。
- 非当前影片的内容从辅助技术及键盘焦点中隐藏；离开首页时移除计时器及事件监听。
- 所有幻灯片共享最大高度，切换不会推挤下方片单。
- 移除了首页大幅介绍中的 `Beijing cinemas`，轮播电影标题按用户后续要求改为加粗白色。
